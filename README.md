# 💡 Li-Fi Data Transmitter

A visible-light communication system that transmits digital data
using LED-based optical communication and receives the data using
an LDR-based receiver.

## Hardware

- Arduino
- LED transmitter
- LDR receiver
- Keypad
- 16x2 LCD
- Supporting interface circuitry

## Working

User input is provided through the keypad. The Arduino processes
the input and transmits the data through modulated visible light.
The receiver detects the optical signal using an LDR and displays
the received information on a 16x2 LCD.
